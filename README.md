# Hospital Data Analysis

## Project Overview
An end-to-end hospital data analysis project
using SQL, Python, and Power BI.

The project focuses on analyzing hospital
operations, patient activity, financial
performance, pharmacy data, and staff
distribution.

## Tools & Technologies
- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Project Components

### 1. SQL Analysis
- Data exploration
- SQL queries and aggregations
- Joins and filtering
- Hospital KPIs
- Patient and billing analysis
- Department analysis

### 2. Python Analysis
- Data loading and inspection
- Data cleaning
- Missing values analysis
- Data type conversion
- Exploratory Data Analysis (EDA)
- Data visualization

### 3. Power BI Dashboard

The dashboard contains six pages:

1. Hospital Overview
2. Patient Activity
3. Department Activity
4. Payment Analysis
5. Pharmacy Analytics
6. Staff Analysis
